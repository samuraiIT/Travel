## 8. Технический раздел: как собирался этот маршрут (роли, скиллы, промт)

### 8.1 Роли/агенты, использованные для сборки

| Роль | Задача |
|---|---|
| **Travel Research Agent** | Поиск актуальных транспортных связей (поезда, самолёты), режимов работы достопримечательностей |
| **Hotel Sourcing Agent** | Подбор эконом-отелей по каждому городу с привязкой к ключевым локациям |
| **Logistics Optimizer** | Расчёт последовательности городов, ночей, минимизация лишних переездов |
| **Document Composer** | Сборка единого структурированного .md-файла с таблицами и чек-листами |

### 8.2 Промт, использованный для генерации маршрута

```
Ты — travel-эксперт по Китаю с 10-летним опытом организации авторских туров.
Дан маршрут: Шанхай – Чунцин – Фужун – Чжанцзяцзе/Тяньмэнь – Гуйлинь/Яншо – Шэньчжэнь – Пекин.
Уже куплены билеты: Москва→Гуанчжоу→Шанхай (28-29.08), Шанхай→Чунцин (31.08).
Финальная дата возврата: 14.09.
Задача:
1. Рассчитать оптимальное количество ночей в каждом городе с учётом
   реального времени в пути между локациями (поезда/самолёты).
2. Для каждого города найти топ-3 бюджетных отеля (эконом-класс, 2-3 звезды)
   в правильной локации (рядом с ключевыми достопримечательностями/вокзалом).
3. Расписать маршрут по дням: что делать утром/днём/вечером.
4. Учесть режимы работы достопримечательностей (Тяньмэньшань, Red Stone Forest, Badaling).
5. Дать рекомендацию по билету SZX→PEK с учётом желания посетить Великую стену.
6. Собрать всё в единый .md файл с таблицами, чек-листом и явным указанием
   источников для каждого фактического утверждения.
Инструменты: веб-поиск (актуальные цены/расписания), анализ скриншотов бронирований.
```

### 8.3 Инструменты (tools/skills), которые потребовались

- **search_web** — сбор актуальных данных о расписаниях поездов, режимах работы парков, ценах на отели.
- **fetch_url** — там, где требовалось глубже проверить конкретную страницу (trip.com booking).
- **Анализ изображений** (скриншоты бронирований) — извлечение точных дат/времени/цен уже купленных билетов.
- **execute_code** — генерация финального .md-файла как единого артефакта.

MCP-серверы или сторонние API не потребовались — вся задача решена комбинацией веб-поиска и обработки вложенных изображений.

## 9. Итоговые выводы

1. Маршрут длиной **16 ночей** идеально ложится на уже купленные билеты без необходимости их менять.
2. Самое узкое место логистики — переезд **Чжанцзяцзе → Гуйлинь** (6–7,5 часов), поэтому он вынесен в отдельный день без активностей.
3. Разница между аэропортами Шанхая (Hongqiao/Pudong) требует отдельного трансфера — не путать при планировании times.
4. Финальная развилка (Шэньчжэнь vs стена) — вопрос приоритета, а не логистики: оба варианта технически реализуемы.
5. Эконом-отели во всех городах маршрута доступны в диапазоне **$10–45/ночь**, что делает бюджет проживания предсказуемым и невысоким.
6. Рекомендуемое действие: забронировать поезда и отели не позднее чем за месяц до поездки — особенно редкий прямой рейс Zhangjiajie→Guilin.
